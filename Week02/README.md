# Week 02 — Enterprise Infrastructure Planning for a Startup Company

**Course:** ITEP 414 – System Administration and Maintenance  
**Program:** Bachelor of Science in Information Technology  
**Prepared by:** Cris-Ann F. Mendoza

## Project Overview
This portfolio project designs the initial IT infrastructure of **ABC Startup Solutions**, a fictional software development company with 20 employees on one office floor. The plan is prepared before purchasing equipment and covers company requirements, hardware, software, networking, topology, system administration roles, recommendations, and reflection.

## Learning Objectives
- Explain System Administrator roles and responsibilities.
- Identify hardware, software, and networking requirements for a small business.
- Prepare professional IT inventories.
- Design an enterprise network topology.
- Create technical documentation using Markdown.
- Present infrastructure planning professionally.

## Challenges Encountered
The most challenging part was translating the business scenario into a practical topology. The design needed to include all required components while also considering security, departmental separation, shared services, backup, and future growth.

## Reflection
This Week 2 project taught me that system administration requires careful planning, organization, and technical decision-making before implementing any IT infrastructure. I learned how to analyze the needs of a startup company and translate those requirements into an appropriate IT infrastructure plan. I gained a better understanding of how hardware, software, networking equipment, servers, security, and backup systems work together to support business operations. I also learned the importance of creating proper documentation because it helps system administrators clearly understand, manage, maintain, and improve an organization's IT environment.

The most challenging task for me was designing the **enterprise network topology**. I needed to make sure that all required components, such as the Internet, ISP modem, router, firewall, switch, wireless access point, server, printer, and different departments, were properly connected. It was challenging to organize the diagram in a way that was both technically logical and easy to understand. Creating the hardware, software, and network inventories was also challenging because I had to determine realistic quantities and identify the purpose of each resource based on the company's 20 employees and four departments.

Planning is important before deployment because it helps prevent unnecessary expenses, configuration problems, security risks, and compatibility issues. A System Administrator needs to understand the organization's requirements before purchasing equipment or deploying services. Proper planning also makes it easier to determine the required network structure, server specifications, backup strategy, security controls, and future expansion needs. Without proper planning, an organization may purchase equipment that does not meet its requirements or create an infrastructure that is difficult and expensive to maintain.

This project will help me become a better System Administrator by improving my ability to analyze requirements, design infrastructure, document technical decisions, and think critically about an organization's current and future needs. It also helped me understand that a System Administrator is not only responsible for fixing technical problems but also for preventing problems through proper planning, security, maintenance, and documentation. The experience I gained from this project will help me become more organized, technically prepared, and confident when working with real-world IT infrastructure.
