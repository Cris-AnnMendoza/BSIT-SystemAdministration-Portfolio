# Week 02 — Enterprise Infrastructure Planning for a Startup Company

**Course:** ITEP 414 – System Administration and Maintenance  
**Program:** Bachelor of Science in Information Technology  
**Prepared by:** Cris-Ann F. Mendoza

## Project Overview
This portfolio project designs the initial IT infrastructure of **ABC Startup Solutions**, a fictional software development company with 20 employees on one office floor. The plan is prepared before purchasing equipment and covers company requirements, hardware, software, networking, topology, system administration roles, recommendations, and reflection.

## Learning Objectives
- Explain System Administrator roles and responsibilities.
- Identify hardware, software, and networking requirements for a small business.
- Prepare professional IT inventories.
- Design an enterprise network topology.
- Create technical documentation using Markdown.
- Present infrastructure planning professionally.

## Challenges Encountered
The most challenging part was translating the business scenario into a practical topology. The design needed to include all required components while also considering security, departmental separation, shared services, backup, and future growth.

## Reflection
The project demonstrated that system administration starts with business and infrastructure planning. Creating inventories and a network topology made it easier to understand how hardware, software, security, backups, and user support depend on one another.
